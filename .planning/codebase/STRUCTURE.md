## Directory Purposes

**`autoascend/`:**
- Purpose: The bot. Everything that decides what to do in NetHack lives here.
- Contains: Python modules and subpackages (`combat`, `item`, `glyph`, `monster_tracker`, `objects`, `soko_solver`).
- Key files: `agent.py`, `global_logic.py`, `plans.py`, `env_wrapper.py`, `strategy.py`, `ladder.py`.
- Rule: Do not import from `nethack_screensaver` or `bench`. Keep pure rule modules free of game access, as `boulders.py`, `prayer.py`, `digging.py` and `ladder.py` already are.

**`nethack_screensaver/`:**
- Purpose: The terminal runtime. Plays games forever, renders them, paces them, and logs results.
- Contains: Loop, rendering, configuration, game runner, staging for research.
- Key files: `player.py` (loop), `game.py` (game runner and `GameResult`), `config.py` (settings).

**`bench/`:**
- Purpose: Benchmark infrastructure. Plays games per commit, stores results, judges experiments, and serves a dashboard and MCP tools.
- Contains: Server, scheduler, worker process, store, metrics, and importers.
- Key files: `cli.py`, `server.py`, `scheduler.py`, `worker.py`, `store.py`, `mcp_server.py`.
- Rule: `worker.py` must stay importable without the `bench` package (its docstring says so).

**`scripts/`:**
- Purpose: Command-line tools for research and benchmarks. Run directly with `uv run python scripts/<name>.py`. Not included in the wheel (`[tool.hatch.build.targets.wheel] packages` lists only `autoascend`, `nethack_screensaver`, `bench`).
- Contains: Benchmarks, scenarios, studies, generators.

**`tests/`:**
- Purpose: pytest suite. `addopts = "-m 'not slow'"` in `pyproject.toml` skips slow tests that play real games.
- Contains: One `test_<module>.py` per module, shared `conftest.py`, `fake_player.py`, `bench_fakes.py`, and `data/` fixtures.

**`.planning/`:**
- Purpose: Research and planning notes. Committed. Not read by the runtime.
- Contains: `research/` (NetHack 5 findings: `ASCENSION-*`, `MEDUSA-NH5.md`, `SCROLL-ID-NH5.md`, etc.), `research/external/` (answers from external models), `hand-games/`, and `codebase/` (the generated maps, currently empty until mapped).
- Note: Several autoascend module docstrings cite `.planning/...` files (for example `autoascend/castle.py`, `autoascend/medusa.py`, `autoascend/telepathy.py`). Those cited paths must exist for the references to be useful.

**`reference/`:**
- Purpose: Local copies of NetHack 3.6.6, NetHack 5.0.0, NLE source, the NetHack wiki, guides, and Reddit/wiki batches.
- Generated: No (downloaded/copied). Committed: No (`.gitignore`).
- Used by: `pyproject.toml` (`nle = { path = "reference/nle-src" }`) and research notes.

**`archive/`:**
- Purpose: Backup of the v0 final state (`screens-v0-final.tar.gz`, `screens-all-branches.bundle`).
- Generated: Yes. Committed: No (`.gitignore`).

**`.venv/`:**
- Purpose: uv-managed virtual environment with NLE and the three packages installed.
- Generated: Yes (`uv sync`). Committed: No.

**`.worktrees/`:**
- Purpose: Git worktrees for parallel work. Empty except for generated directories.
- Generated: Yes. Committed: No.

**`.superpowers/`, `.pytest_cache/`:**
- Purpose: Tool caches. Generated. Committed: No.

**`.gsd/`, `.claude/`:**
- Purpose: Local tool and assistant settings. `.claude/settings.local.json` is machine-specific. `.gsd/` is a tooling sentinel.
- Committed: No (neither path is tracked by git; they are present in the working tree only).

## Key File Locations

**Entry Points:**
- `bin/nethack-screensaver`: Terminal launcher (bash).
- `zsh/nethack-screensaver.zsh`: Idle hook for `~/.zshrc`.
- `nethack_screensaver/player.py`: Python player loop (`python -m nethack_screensaver.player`).
- `bench/cli.py`: `screens-bench` console script (`main`).
- `bench/mcp_server.py`: MCP server for Claude (`.mcp.json`).
- `bench/worker.py`: Child process script that plays games for a commit.
- `scripts/benchmark.py`: Headless benchmark command.

**Configuration:**
- `pyproject.toml`: Package metadata, dependencies, `[project.scripts]`, wheel packages, pytest markers and options, and the NLE path source.
- `uv.lock`: Locked versions.
- `.python-version`: `3.13`.
- `.mcp.json`: MCP server command and `SCREENS_BENCH_PYTHON` path.
- `~/.config/nethack-screensaver/config.toml` (user-owned, read by `nethack_screensaver/config.py` via `paths.config_path`): optional screensaver settings.
- `.claude/settings.local.json`: Local Claude Code settings.
- `.gitignore`: Ignored paths (`.venv/`, `__pycache__/`, `.pytest_cache/`, `.superpowers/`, `reference/`, `.worktrees/`, `archive/`, `*.nbi`, `*.nbc`).

**Core Logic:**
- `autoascend/agent.py`: Agent and action primitives.
- `autoascend/global_logic.py`: Milestone-driven strategy selection.
- `autoascend/plans.py`: Strategy definitions and role tiers.
- `autoascend/combat/fight_heur.py`: Fight decisions.
- `autoascend/item/item_manager.py`, `autoascend/item/inventory.py`: Item priorities and inventory handling.
- `autoascend/soko_solver/search.py`, `autoascend/soko_solver/maps.py`: Sokoban solver.
- `nethack_screensaver/game.py`: Game runner.
- `bench/scheduler.py`: Job scheduling and experiment judgement.
- `bench/store.py`: Results persistence.

**Testing:**
- `tests/conftest.py`: Shared pytest setup.
- `tests/fake_player.py`, `tests/bench_fakes.py`: Fakes for the player and bench.
- `tests/test_*.py`: Module tests (for example `tests/test_game.py`, `tests/test_player.py`, `tests/test_bench_scheduler.py`, `tests/test_plans.py`, `tests/test_castle.py`).
- `tests/data/`: Recorded fixtures (`bench_xlog_sample.txt`, `soko_real_*.json`, `*.npy` tty dumps).

## Naming Conventions

**Files:**
- Python modules: `snake_case.py` (`global_logic.py`, `env_wrapper.py`, `monster_tracker.py`).
- Tests: `tests/test_<module>.py`. For bench: `tests/test_bench_<part>.py` (e.g. `test_bench_scheduler.py`, `test_bench_server.py`).
- Subpackages: lower-case single words (`combat`, `item`, `glyph`, `objects`).
- Generated data: `objects/data.py` is produced by `scripts/gen_objects_data.py`. Do not edit it by hand.
- Research notes: `UPPERCASE-NH5.md` or `UPPERCASE.md` in `.planning/research/` (for example `MEDUSA-NH5.md`, `ASCENSION-PLAN-NH5.md`).
- Hand-game records: `.planning/hand-games/<name>/NOTES.md` plus `meta.json`.
- Shell: `kebab-case` (`nethack-screensaver.zsh`, `nethack-screensaver`).

**Directories:**
- Python packages: `snake_case` or single lower-case words, each with `__init__.py` (`autoascend/combat/__init__.py`, `autoascend/item/__init__.py`, `bench/__init__.py`). Note that `scripts/` and `tests/` have no `__init__.py` at the top level.
- Planning directories: lower-case with hyphens (`hand-games`), except `research/` and `codebase/`.

**Identifiers (from the code):**
- Functions and variables: `snake_case` (`run_game`, `choose_strategy`, `frame_delay`).
- Classes: `PascalCase` (`Agent`, `GlobalLogic`, `EnvWrapper`, `GameResult`, `ProcessWorker`).
- Module constants: `UPPER_SNAKE_CASE` (`UNSTICK_AFTER`, `CHARACTER`, `AGENT_ARGS`, `STRATEGIES`, `DEFAULT_PLAN`).
- Strategy names: lower-case words (`pilgrim`, `daredevil`, `sightseer`, `treasure`).
- Milestones: `Milestone.UPPER_SNAKE_CASE` (for example `Milestone.FIND_SOKOBAN`), aliased as `M` in `autoascend/plans.py`.

## Where to Add New Code

**New bot behaviour (decision logic):**
- Pure rule or calculation with no game access: a new module in `autoascend/` (for example `autoascend/<name>.py`), with stdlib and numpy only, plus `tests/test_<name>.py`.
- Behaviour that needs the game: a method on `Agent` in `autoascend/agent.py` if it is a primitive (move, fight, eat). Keep the decision logic in the standalone module and call it from `agent.py`.
- Milestone-level behaviour: add a branch in `GlobalLogic` (`autoascend/global_logic.py`) and a `Milestone` value in the milestone enum used by `autoascend/plans.py`.

**New combat rule:**
- Implementation: `autoascend/combat/fight_heur.py` (heuristic) or `autoascend/combat/movement_priority.py` (movement). Stair escapes go in `autoascend/combat/stair_escape.py`.
- Tests: `tests/test_fight_heur.py`, `tests/test_stair_escape.py`.

**New item rule:**
- Priority or usage: `autoascend/item/item_priority_base.py` (base), `autoascend/item/item_manager.py` (manager), or a category module (`accessories.py`, `scrolls.py`, `wishes.py`, `shop_sell.py`).
- Object data: change `scripts/gen_objects_data.py` and regenerate `autoascend/objects/data.py`, do not hand-edit.
- Tests: `tests/test_accessories.py`, `tests/test_scrolls.py`, `tests/test_wishes.py`, `tests/test_shop_sell.py`, `tests/test_inventory_unload.py`.

**New strategy or plan:**
- Definition: `autoascend/plans.py` (`STRATEGIES`, `plan_for`, `ROLE_TIERS`, `TIER_WEIGHTS`).
- Tests: `tests/test_plans.py`.
- Document the strategy in `README.md` (the "Goals" paragraph) and `CHANGELOG.md`.

**New special-level or dungeon-branch logic:**
- Sokoban: `autoascend/soko_solver/` (solver and maps).
- Castle, Medusa, quest portal: `autoascend/castle.py`, `autoascend/passtune.py`, `autoascend/medusa.py`, `autoascend/quest_portal.py`. Tests: `tests/test_castle.py`, `tests/test_medusa.py`, `tests/test_quest_portal.py`, `tests/test_passtune.py`.

**New screensaver feature (display, pacing, config):**
- Rendering: `nethack_screensaver/render.py`. Tests: `tests/test_render.py`.
- Pacing: `nethack_screensaver/pacing.py`. Tests: `tests/test_pacing.py`.
- Config key: `nethack_screensaver/config.py` (`Config`, `load_config`). Tests: `tests/test_config.py`. Document in `README.md`.
- Game-run behaviour: `nethack_screensaver/game.py`. Tests: `tests/test_game.py`.

**New bench metric or report:**
- Metric: `bench/metrics.py` (`METRICS`). Tests: `tests/test_bench_metrics.py`.
- Stats: `bench/stats.py`. Tests: `tests/test_bench_stats.py`.
- HTTP endpoint: `bench/server.py` (`App` method and `make_handler` route). Tests: `tests/test_bench_server.py`.
- MCP tool: `bench/mcp_server.py`. Tests: `tests/test_bench_mcp.py`.
- Dashboard: `bench/static/index.html`.

**New research or analysis script:**
- `scripts/<name>.py`, with a module docstring that explains the usage line (as the existing scripts do). Shared helpers go in `scripts/scenario_lib.py` or in the package the helper belongs to, not in `scripts/`.

**New tests:**
- `tests/test_<module>.py`. Use `tests/conftest.py` for shared setup and `tests/fake_player.py` or `tests/bench_fakes.py` for fakes. Mark anything that plays real games with `@pytest.mark.slow`.

**Utilities:**
- Bot-wide helpers: `autoascend/utils.py`. Glyph helpers: `autoascend/glyph/`. Object helpers: `autoascend/objects/utils.py`. Item helpers: `autoascend/item/utils.py`.
- Bench helpers: `bench/gitrefs.py` (git), `bench/filters.py` (query parsing).

**Research notes:**
- `.planning/research/<NAME>-NH5.md` for NetHack 5 findings. Reference them from module docstrings, as `autoascend/castle.py` and `autoascend/medusa.py` do.

## Special Directories

**`.venv/`:**
- Purpose: uv virtual environment (Python 3.13).
- Generated: Yes (`uv sync`).
- Committed: No.

**`reference/`:**
- Purpose: NetHack and NLE source and wiki material.
- Generated: No (copied in). Committed: No.
- Note: `reference/nle-src` is a build dependency. `uv sync` needs it to exist.

**`archive/`:**
- Purpose: Backups of the v0 final state.
- Generated: Yes. Committed: No.

**`.worktrees/` and cache worktrees:**
- Purpose: Git worktrees. The bench server puts its per-commit worktrees under `~/.cache/screens-bench/worktrees` (`SCREENS_BENCH_CACHE`), not inside the repo.
- Generated: Yes. Committed: No.

**Data directories outside the repo:**
- `~/.config/nethack-screensaver/config.toml`: user settings.
- `~/.local/state/nethack-screensaver/`: `games.jsonl`, `player.log`.
- `~/.local/share/screens-bench/`: `results.db`, `worker.log` (`SCREENS_BENCH_DATA`).
- `~/.cache/screens-bench/`: worktrees (`SCREENS_BENCH_CACHE`).
