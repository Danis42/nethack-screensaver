# Quick task: skip seeds where a change cannot fire (trigger-gated experiments)

**Owner decision (2026-11-17):** efficiency research recommendation 1, approved with the SPRT (261117-kpa).

## Why it is exact

A/A job 8: a commit replays its own games exactly (1,999/1,999). A candidate's game can only differ from the
baseline's once the baseline game reaches a state where the candidate's code acts differently. If a stored baseline
game never reaches the change's trigger condition, the candidate plays the same game: a concordant pair, which adds
nothing to b or c, the only inputs of both decision rules. The estimate (b - c) / n keeps the full n.

Risk: the trigger is a claim about the change. An audit plays every untriggered seed with seed % 10 == 0; a single
audited seed whose candidate game differs from the baseline game fails the job ("trigger missed a divergence").

## Tasks

1. Recording (bot side, play unchanged): `nethack_screensaver/visits.py`, a `snapshots.Recorder` subclass adding
   `snapshots["visits"]`: per "dungeon:level" the first turn and the milestones held there. `game.py` uses it and
   passes the milestone (net zero lines). Tests.
2. Bench side: `bench/triggers.py`: `TRIGGERS` registry (pure functions of a stored game, KeyError when the game
   has no visit log), first trigger `mines_unwanted` (on a Gnomish Mines level under a milestone that does not want
   the Mines; the condition of plan 02-05's `_on_wrong_branch`). `View`: the scheduler's store reads with skipped
   candidate seeds filled from the baseline game and audited seeds checked. Scheduler, server, MCP: optional
   `trigger` on experiments; a baseline without visit logs is refused at submit. Tests.
3. Gate: `python -m bench.gate trigger-skip` when no bench job runs (after jobs 20/21, before the fresh baseline);
   amend `Gate: job N`, merge to main, then the fresh baseline records visits.

## Done when

- `uv run pytest` passes, ratchets respected (or a raised limit is shown to the owner).
- Gate job passes 100/100 (recording does not change play) before merge.
