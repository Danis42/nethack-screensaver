Run it with `--games 400` (more if fewer than 300 prayers were seen) and paste the table into a new `.planning/phases/01-midgame-survival/01-HUMAN-STUDY.md` under `## Prayer messages (NetHack 3.6, NLD-NAO)`, with the command line used.

RESEARCH Pattern 3 lists the mechanics to expect (too-soon prayer: "displeased" plus Luck -3; angry god: smiting/anger messages; success: trouble fixed, e.g. hunger reset), but only census strings go into the tuples; note any expected string the census did not show.

Tests: `tests/test_prayer.py` (classifier cases from the behavior block, one case per marker), `tests/test_nld_study.py` (message_line and status on synthetic numpy frames shaped (24, 80) uint8).
